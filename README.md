# mtn.mediaview

Плагин просмотра картинок и видео для файлового менеджера [MTN2](https://github.com/Laex/MTN2) на
[libmpv](https://mpv.io). **F3** на файле открывает его во вкладке просмотра.

*A picture and video viewer plugin for the [MTN2](https://github.com/Laex/MTN2) file manager, built on libmpv.
F3 on a media file opens it in a viewer tab. Keys are listed in [help.md](dist/mtn.mediaview/help.md).*

> Ранняя версия. Проверялась одним человеком на одной машине (Windows 10 x64, NVIDIA); возможны ошибки.

## Возможности

- Видео и картинки любых форматов, которые понимает mpv/ffmpeg (HEVC, AV1, MKV, WebP, AVIF, GIF...),
  без установки кодеков в систему; аппаратное декодирование (d3d11va).
- Масштаб колесом вокруг указателя, перетаскивание увеличенного кадра, поворот, режим «вписать в окно».
- Скорость воспроизведения 0.25x–4x, покадровый шаг, перемотка без сброса паузы, выбор звуковой дорожки.
- Действие в конце ролика: остановиться, повторить или перейти к следующему файлу.
- Листание файлов папки в порядке панели, выделение файлов клавишей Insert.
- Файлы внутри архивов и на sftp – через файловый слой MTN2, без ограничения размера.
- Полноэкранный режим, несколько вкладок просмотра одновременно.
- Буквенные клавиши работают и в русской раскладке.

Полный список клавиш – в [справке](dist/mtn.mediaview/help.ru.md) (в MTN2: **Параметры → Плагины... → Справка**).

## Установка

Нужен **MTN2 0.3.16 или новее**, Windows x64. На более старых сборках плагин ставить нельзя: таблица функций
хоста там короче, и плагин может уронить программу при запуске.

1. Скачайте `mtn.mediaview-<версия>-win64.zip` со страницы [Releases](../../releases) и распакуйте папку
   `mtn.mediaview` в `plugins\` рядом с `MTN2.exe`.
2. Положите в ту же папку `libmpv-2.dll` (x64). В архив плагина она не входит. Взять её можно из сборок
   [shinchiro/mpv-winbuild-cmake](https://github.com/shinchiro/mpv-winbuild-cmake/releases): архив
   `mpv-dev-x86_64-*.7z`, внутри – `libmpv-2.dll`.
3. Перезапустите MTN2. Чтобы открывать файлы из архивов и с sftp, разрешите плагину `vfs.read`:
   **Параметры → Плагины... → Разрешения...**.

Должно получиться:

```text
MTN2.exe
plugins\
  mtn.mediaview\
    mediaview.dll
    libmpv-2.dll
    plugin.json
    mediaview.conf
    help.md
    help.ru.md
```

Параметры libmpv (декодирование, вывод, размер кэша соседних файлов) можно переопределить в `mediaview.conf`.

## Известные ограничения

- Для прямой обработки **Esc/F10** и сохранения картинки при **F11** нужен MTN2 **0.3.16.7 или новее**.
  Esc/F10 сразу закрывают просмотр, сохраняя выбранный полноэкранный режим для следующего открытия.
- Курсор панели и выделение (Insert) переносятся в панель при закрытии вкладки, а не сразу.
- Файл из архива или с sftp MTN2 сначала копирует во временный файл; большое видео начинает играть после
  копирования.
- Режима миниатюр нет.

## Сборка

Visual Studio 2022 Build Tools (MSVC x64) с CMake и Ninja из их состава:

```bat
build.cmd
```

Результат – `dist\mtn.mediaview\mediaview.dll`. SDK mpv для сборки не нужен: плагин загружает `libmpv-2.dll`
во время работы.
